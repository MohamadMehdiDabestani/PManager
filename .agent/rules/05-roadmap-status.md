# Project Roadmap & Status Tracking
- Always read `ROADMAP.md` in the repository root at the start of a new task or session to check which phases are completed, what architectural decisions are locked in, and which phase/task is currently active.
- Whenever a phase, milestone, or significant feature is completed, update the checkboxes and current status banner in `ROADMAP.md`.
- Architectural locks to remember: shadcn/ui design system (`@/components/ui/*` with `industrial` 56px size), Drizzle ORM (`@cmms/db`), CASL + `accessibleWhere` (`@cmms/core/auth`), Auth.js, simple spare parts inventory, and notification fallback priority `SMS -> EITAA -> EMAIL`.
